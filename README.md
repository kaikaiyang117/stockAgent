# SignalTrace · 股价异动解释 Agent

一个完全自包含的前端演示项目：把模拟行情、交易日历、公告、新闻、行业事件和财务信息映射到交易日，为明显异动日生成带证据边界的解释时间线。

## 启动

环境要求：Node.js 18+。

```bash
npm install
npm run dev
```

打开终端提示的本地地址即可。生产构建：

```bash
npm run build
npm run preview
```

## 交互流程

1. 首屏默认选中 2026-09-11，这是内置的明显上涨日（+12.87%）。
2. 点击价格图中的任意节点，右侧日期、事件时间线和 Trace Agent 会同步更新。
3. 点击时间线事件，右侧“事件详情”展示标题、交易所时间、类型、来源、摘要和证据。
4. 点击浮动 Agent 的因素卡片，会定位到对应事件并让事件详情同步切换。
5. 顶部“状态演示”可以查看正常视图、空数据、范围外事件和异常数据提示。

## 实现方案

- Vite + React + TypeScript。
- 图表使用原生 SVG，支持键盘 Enter/Space 选择交易日，不引入图表库。
- 核心领域逻辑与 UI 解耦：`src/domain.ts` 负责时间映射、异常判定和事件筛选，`src/agent.ts` 负责确定性解释规则。
- 运行数据全部位于 `src/data.ts`，无 API、数据库和服务端状态。
- 领域类型与映射规则详见 [`docs/data-model.md`](docs/data-model.md)，需求验收基线详见 [`docs/requirements.md`](docs/requirements.md)。

## 测试

```bash
npm test
```

当前包含 6 个核心测试：

- 盘后事件映射到下一交易日。
- 周末事件映射到下一交易日。
- 非 `Asia/Shanghai` 时区的事件先转换到交易所时区，再进行交易日映射。
- 15:00 事件仍映射到当日。
- 15:01 事件映射到下一交易日。
- 证据不足的因果假设被标记为低置信度并显示不确定性。

## 已知限制

- 这是模拟数据演示，不代表真实证券、真实公司或真实市场事件。
- Agent 是规则和预设结果，不是真实 LLM，也不具备预测能力。
- 当前只覆盖一个内置标的和固定日期范围。
- 图表为收盘价趋势 + 高低区间标记，不实现复杂技术指标。
- “空数据”等状态通过状态演示入口触发，不代表真实后端请求失败。
