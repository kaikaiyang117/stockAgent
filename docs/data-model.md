# 数据模型与领域规则

## 数据实体

类型集中在 `src/types.ts`：

- `TradingDay`：交易日历，包含 `date` 与 `isTradingDay`。
- `MarketData`：模拟 OHLCV 行情，包含涨跌幅以及 `isAnomaly` 异动标记。
- `Event`：公告、新闻、行业事件或财务数据。除了原始发布时间，还保存 `mappedTradingDate`、`mappingReason` 与 `mappingStatus`，使 UI 能区分已映射、范围外和异常数据。
- `Evidence`：证据文本、来源和强度（强/中/弱/证据不足）。
- `ExplanationFactor`：模拟 Agent 输出的解释因素，包含关联事件、分类、依据、置信度和不确定性。

## 时间映射

`src/domain.ts` 中的 `mapEventToTradingDate` 会先解析事件携带的 ISO 时间，再通过 `Intl.DateTimeFormat` 转成 `Asia/Shanghai`（交易所时区）的日期和时间：

1. 日期是交易日且时间不晚于收盘：映射当日（覆盖开盘前和交易时段）。
2. 交易日 15:00 之后：映射到下一交易日。
3. 日期是周末/非交易日：映射到下一交易日。
4. 日期超出内置交易日历，或其后没有下一交易日：标记 `out-of-range`。
5. 时间无法解析：标记 `invalid`，不进入事件时间线和 Agent 解释。

所有展示时间都再次使用交易所时区格式化，避免直接展示原始时区字符串。

## 异动判定

`detectAnomalies` 使用确定性的绝对涨跌幅阈值（默认 8%），同时保留数据中的人工标记。内置演示中 2026-09-11 涨跌幅为 +12.87%，因此被标记为“异动上涨”。

## Agent 解释规则

`src/agent.ts` 不接入真实模型，只根据已映射的事件 ID 返回确定性结果：

- 盘后合作公告 → “合作框架公告改善预期”，分类为因果假设，置信度 74%。
- 产业消息 + 行业规范 → “行业规范与产业消息形成共振”，分类为时间相关性，置信度 61%。
- 匿名讨论 + 放量 → “成交量放大与资金传闻”，分类为证据不足的因果假设，置信度 18%。

所有因果假设都会显示依据和不确定性提示，且不会使用“已证实”“导致”等确定性措辞。
