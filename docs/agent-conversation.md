# Agent 开发记录

这是本次项目实现过程的精简可复核记录，保留需求、判断、实现和验证结论。

## 1. 需求读取

- 用户请求：开始执行“股价异动解释 Agent”项目。
- 输入材料：`题目.md` 与项目实现说明。
- 仓库状态：工作区为空，没有已有技术栈或代码可复用。
- 约束判断：所有数据必须内置；不接真实 API、真实 LLM、数据库或预测能力。

## 2. 关键设计决策

- 技术栈选择 Vite + React + TypeScript，保持启动和提交成本低。
- 图表使用原生 SVG，避免引入图表库，确保模拟数据可控且可复现。
- 先实现领域逻辑，再实现 UI：时间映射接口接收交易日历，Agent 只接收已映射事件。
- 交易所时区统一为 `Asia/Shanghai`；事件原始时间使用带偏移 ISO 字符串。
- 将“证据不足的资金传闻”作为显式低置信度因果假设，演示不能越界归因。

## 3. 实现阶段

1. 创建 `docs/requirements.md`，拆出功能、非功能、范围边界和验收 checklist。
2. 创建 `src/types.ts`、`src/data.ts`，建立实体类型和固定模拟数据。
3. 创建 `src/domain.ts`、`src/agent.ts`，实现时间映射、异动判定、事件筛选和解释规则。
4. 创建 `src/domain.test.ts`，覆盖盘后、周末和证据不足三类要求。
5. 创建 React 页面、SVG 行情图、事件时间线、详情面板和浮动 Agent。
6. 增加 Loading、Empty、Out-of-range、Invalid Data 和无事件状态入口。
7. 创建 README 与数据模型说明，去除外部字体依赖，保证数据与核心演示不需要联网。

## 4. 验证结果

- `npm test`：3 tests passed。
- `npm run build`：TypeScript 检查通过，Vite production build 成功。
- 页面默认异动日为 2026-09-11；盘后公告映射到该日，周末事件映射到 2026-09-14。
- 浏览器自动化检查在当前桌面环境的 CUA 入口超时，因此未将该工具失败误判为应用故障；可用本地 `npm run dev` 手动检查交互。
